srv1-backup

A private backup tool for one person's own server. It is not a public service and does not accept other users.

What it does

Every night srv1-backup makes an encrypted backup of its owner's server and stores it in the owner's own Google Drive. It uses the Google Drive API only to create, read and delete the backup files in a dedicated backup folder of that Drive.

Who uses it

Only the owner of the server, who is also the owner of the Google account and of this Google Cloud project. Nobody else signs in to this application.

Your data

Backups are encrypted on the server before upload, with a password known only to the owner. No data is sent anywhere except the owner's own Google Drive. See the privacy policy and the terms of service.
